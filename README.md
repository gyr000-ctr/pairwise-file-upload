# pairwise-file-upload

## 题面

文件上传功能一上线就出现越权落盘：文件名携带 ../ 可穿越到任意目录；双扩展名与大小写变体绕过白名单；仅凭扩展名判断类型未做内容嗅探；上传无大小上限可耗尽磁盘；临时文件处理后残留未清理。upload/handler.py 是核心，tests/test_upload.py 15个红。要修的是：规范化路径并拒绝目录穿越；按内容嗅探与扩展名双重校验；统一扩展名大小写与变体归一；限制单文件与总量大小上限；上传失败与成功后清理临时残留。

## 运行方式

```bash
python -m pytest tests -q
```

初始状态应为 `15 failed`，无 collection error；`tests/` 目录不可修改。
